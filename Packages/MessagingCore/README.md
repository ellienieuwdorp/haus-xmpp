# MessagingCore

Application-owned coordination across MessageStore, XMPPProtocol and OMEMO. `OutboxSender` serializes prepared send claims. `StreamPersistence` binds one immutable account to revisioned stream state, atomic server acceptance and encryption replay authorization. `ArchiveSynchronizer` orders ciphertext/message commits before archive checkpoints and inbound acknowledgements; abandoned pages disconnect safely.

Acquire the store transport lease before running send/recovery operations. Cancellation before transport returns a claim to queue; a completed or uncertain socket write is unconfirmed unless an authenticated server acknowledgement has already advanced it. Stale callbacks cannot regress server acceptance. Exact-ciphertext retry policy remains separate from recipient delivery.

`swift test --package-path Packages/MessagingCore` covers sender ordering, cancellation, account/revision fences, corrupt snapshots and refusal to resume plaintext or unknown encrypted operations. Protocol and OMEMO packages add live server and cryptographic interoperability checks.

Group catch-up first restores validated room membership/provenance on the fresh transport for every persisted room, then queries the own-account archive and each room archive. It does not join rooms or approve fingerprints. Room queries revalidate non-anonymous, members-only membership through the protocol module. Each room has a separate account-scoped cursor; authenticated group sender identity and archive timestamps go to `receiveGroup`. New/changed fingerprints may leave durable pending ciphertext, which is a handled disposition without being shown as authenticated plaintext.

An explicit room membership/feature rejection or correlated IQ error leaves that room’s checkpoint untouched and allows own-account/direct catch-up. Malformed responses, cancellation, storage failures and transport failures still abort and disconnect. Historical group sender provenance is independently validated by the protocol module; unavailable room access never authenticates a nickname or permits a send. A page's durable message/pending commits precede its checkpoint and stream acknowledgments. Errors/cancellation disconnect, and cancellation immediately after a message commit cannot advance that page's cursor. Seven deterministic archive tests verify room refresh order, paged cursor/account separation, undurable message failure, access revocation, acknowledgment failure after commit and cancellation. These coordination tests complement, but do not replace, the protocol/service group's live archive tests.

Unverifiable encrypted group content inside an otherwise authenticated archive wrapper records a bounded, content-free rejection receipt before that page’s cursor. It is never rendered as authenticated text. Missing rejection provenance remains fatal; invalid outer MAM wrappers are rejected by XMPPProtocol.
