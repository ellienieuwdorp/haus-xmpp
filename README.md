# XMPP iOS

Research and planning for an iPhone-first XMPP messenger with reliable notifications, full OMEMO interoperability, core message reactions, excellent local search, rich media, and a modern native interface.

Start with the [preliminary research index](docs/preliminary/README.md) and [executive summary](docs/preliminary/00-executive-summary.md).

This is a research-stage repository, not a runnable app. `xmpp-ios` is a working directory name, not a final product name. No third-party application code has been incorporated.
